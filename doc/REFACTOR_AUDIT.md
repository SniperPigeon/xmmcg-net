# 重构范围复核

基准为 legacy 分支的 80da1ac4。保留已确认的业务变更：独立完整谱面投稿、可选歌曲阶段与一次抽选、简化互评、大小号绑定，以及上传资源迁往 R2。历史数据通过一次性迁移处理，不加入旧竞标 API 或两阶段运行时兼容层。

## 已恢复的范围外改动

| 项目 | 复核结果 |
| --- | --- |
| 数据库 | 生产与开发继续使用 SQLite，移除 PostgreSQL 驱动、DATABASE_URL 切换与相关建议 |
| 部署 | 保留 Nginx + Gunicorn、/opt/xmmcg/venv、原 worker/线程/超时/socket/日志配置、原前端部署目录 |
| SQLite 备份 | 恢复原备份脚本、systemd 服务及定时器 |
| 配置读取 | 保留进程环境变量优先、凭证文件优先于 .env 的原有规则；两份文件不额外合并 |
| 上传限制 | 恢复原音频 10 MB、封面 2 MB、视频 20 MB、谱面文本 1 MB 和每用户 3 首歌曲的默认值；恢复 WMA/GIF 格式接受范围 |
| 原账户接口 | 保留资料更新的 PUT/PATCH、中文响应与原有返回结构；恢复修改密码后原会话失效的行为；移除额外添加的登录/注册频率限制 |
| 注册页面 | 保留用户名 3–20 字符及原 QQ 格式约束，小号绑定字段属于已确认的新需求 |
| 评分导出 | 恢复中文工作表标题、分组表头、颜色、冻结位置与按谱面 ID 排序；署名仍优先个人资料中的谱师名义；仍去掉一个最高分和最低分后平均，并保留原 round 舍入口径 |
| 中文界面 | 恢复“小妹妹唱歌net”浏览器标题和“用户注册”等原有文字；保留个人中心注册时间；恢复原中文字段帮助并为新增管理字段补充中文标签 |

评分导出中两阶段作者列按已确认的新业务合并为“谱师”；旧共同作者仍保存在数据中，并用于排除本人评分。其他中文数据不翻译、不改写。

## 必要的实现调整

- SQLite 没有行级 SELECT FOR UPDATE 锁。写事务使用 IMMEDIATE 模式和 30 秒锁等待；R2 上传在数据库写事务外执行。已用真实 SQLite 文件的并发连接验证真爱票额度不会被并发提交突破。参见 [Django SQLite 事务说明](https://docs.djangoproject.com/en/6.0/ref/databases/#sqlite-notes)。
- Session 登录继续保留，前端检查实际会话；去掉的仅是前端占位 Bearer token。
- 评分保留小数，修复原先前端允许小数、后端转整数的不一致；本人评分限制和真爱票额度由后端统一校验。
- 保留已完成评分，补齐评分任务时不再清空历史记录。
- Net 转发只改变文件读取来源及同步状态记录，不修改谱面正文；使用原接口要求的文件字段名。
- R2 桶 CORS 合并已有规则，避免覆盖其他来源的配置。私有桶静态资源经稳定地址读取，保留原 Django Admin 的相对 CSS/JS 资源引用。
- 依赖更新用于修复检查中发现的问题，保留 Vue、Vite、Element Plus、Django、DRF、Session、SQLite 和 Nginx/Gunicorn 技术栈。

## 联调边界与证据

- 使用用户提供的 SQLite 的独立副本，原文件以哈希核对未改变。
- 用户、歌曲、谱面、公告、评分任务及评分记录数量核对一致；旧半成品归档属于已确认的迁移规则。
- 中文内容、谱师名义、有效评分、评语、真爱票、资源路径及共同作者逐项核对。
- 真实 R2 完成认证投稿、读回校验、重复投稿去重、签名读取、ZIP 下载和配置来源的 GET/OPTIONS CORS 检查。
- 联调强制关闭 Net 同步，拦截 Net 上传函数及所有非 R2 网络地址；实际 Net 请求为零。
- 只使用独立前缀的临时 R2 对象，验证后删除；不把真实用户素材用作上传测试。
